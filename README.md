## 概要
- **I2C I/F**: RRH-G101AボードのESP-WROOM-02 I2C I/F に接続されているデバイス、または外部接続コネクタに接続されるデバイスの制御サンプルです。  
ボード内部には「RTC」「IO-EXP」「ADS1115」があり、外部は「PCA9515A」を介してデバイスと接続ができます。
- **動作モード**: ボード内の「SW2」で動作モードを切替えられます。モードは０（通常），１（ADS1115連続読み取り），２（時刻同期），３（リレー接点リフレッシュ）
- **起動直後の動作**: Wi-Fiへの接続が開始され、常時ＯＮ設定のリレーＲＬ４がＯＮし、ＬＥＤのＬＤ４は、起動後１秒間隔で点滅を繰り返します。  
起動時はモード０で、ＲＴＣの読込表示、ＡＤＳ１１１５の４ＣＨ分のデータ表示およびＳＷ１(ISO-IN1)とISO-IN2の入力まりとなる。  
ＳＷ１(ISO-IN1)は、モード切替用、ISO-IN2は、リレーのシーケンスＯＮ／ＯＦＦの動作用です。
- **SW1(ISO-IN1)の動作**: ＳＷＯＮの間ブザーがなり、ボタンを押すたびにモード０⇒１⇒２⇒３⇒０と繰り返され、ボタンを離して２秒後にそのモードの動作に入ります。  
２秒以内にボタンをクリックするとモードは移行していきます。
- **ISO-IN2の動作**: ISO-IN2の入力がクリック状態を検出すると、リレーＯＮシーケンスが動作し、ＯＮ状態で入力がクリック状態を検出するとリレーＯＦＦシーケンスが動作します。  
リレーＯＮシーケンスは、ＲＬ１が即ＯＮ、１０秒後にＲＬ２がＯＮ、１５秒後にＲＬ３がＯＮになります。  
リレーＯＦＦシーケンスは、ＲＬ３が即ＯＦＦ、５秒後にＲＬ２がＯＦＦ、１５秒後にＲＬ１がＯＦＦとなります。
- **モード１の動作**: 連続でＡＤＳ１１１５の全４チャンネルのデータをサンプリングし、１０２４回取得するとその全データを表示します。  
１２８ＳＰＳですので、４ＣＨ１回のサンプリングで約３１．２５ｍＳかかり、１０２４回取得するまで約３２秒程度かかり、その後に全データをシリアルポートにデータを出力します。  
サンプリング中にSW1(ISO-IN1)の信号を検出すると中断されモードが変更されます。
- **モード２の動作**: ＲＴＣの時刻を同期させるモードです。Wi-Fiに接続状態でNTPクライアントが利用可能な場合に、NTPサーバーから時刻を取得しRTCに時刻を設定します。  
NTPサーバーへの時刻取得は６０秒間隔で行われているため、同期するまで最大で６０秒程度かかります。また、同期開始し、時刻取得ご設定するまでのタイムラグが発生します。
- **モード３の動作**: ＲＬ１～ＲＬ４の全リレーを約０．１間隔でＯＮとＯＦＦを繰り返す動作をします。  
リレーに１５０ｍＡ程度の電流を流してこの動作を行うことで、リレー接点の自浄が期待されます。
- **ＬＣＤ動作**: 外部のＩ２Ｃコネクタ「Ｊ３」にＡＱＭ１６０２を５Ｖ電圧で接続し、そのＬＣＤに起動時にメッセージが表示されます。

## 動作環境
- **ハードウェア**: 
  - IOT Integrated Controller V1　RRH-G101A REV-A (ESP8266搭載)
- **開発ツール**: PlatformIO (VSCode)
- **使用ライブラリ**: 
  - [TaskScheduler](https://github.com/arkhipenko/TaskScheduler)
  - [ADS1X15](https://github.com/chandrawi/ADS1x15-ADC)
  - [NTPClient](https://github.com/arduino-libraries/NTPClient)
  - [TCA9534-GPIO](https://github.com/Beirdo/Arduino-TCA9534)
  - [RDLib_IIC_RW_Base](https://github.com/rinwado/rdlib_iic_rw_base)
  - [RDLib_IIC_SmallLcds](https://github.com/rinwado/rdlib_iic_small-lcds)
  - [RDLib_IIC_S3539x](https://github.com/rinwado/rdlib_iic_s3539x)
  - Ticker (ESP8266 Core内蔵)

## 接続設定
- **JP1設定**: LED側にジャンパー（GPIO16 をLED LD4に接続します）
- **JP2設定**: IO14機能　ＯＦＦ（GPIO14 として利用します）
- **JP3設定**: CH1差動ＡＭＰゲイン ＯＦＦ（ゲインｘ１）
- **JP4設定**: CH2差動ＡＭＰゲイン ＯＦＦ（ゲインｘ１）
- **JP5設定**: Buzzerジャンパー ＯＮ（GPIO13 をブザー制御にセット）
- **JP6設定**: VFPジャンパー ＯＦＦ（ブザー電圧標準）
- **シリアル通信**: 115200 bps

## セットアップと書き込み
1. VSCodeでこのプロジェクトフォルダを開きます。
2. PlatformIOの `Upload and Monitor` を実行します。
3. シリアルモニターにタスク実行ログ、ＡＤＣデータやボタン押下・離上情報などが表示されます。
